# Inference

The inference script processes every supported radiograph directly inside one `--data-dir`. It accepts BMP, PNG, JPEG, and TIFF inputs; files in subdirectories are not included. For a folder such as `batch1`, all root-level images are inferred in one run.

Run all commands from the repository root:

```bat
cd /d <github_repo_location>
```

## Install

The recommended setup creates the pinned CUDA environment, including PyTorch 2.5.1 with CUDA 12.4:

```bat
conda env create -f inference\environment.yml
conda activate perthesmetrics
```

For a `pip` setup, install a CUDA-compatible PyTorch build first using the command generated by the [PyTorch installation guide](https://pytorch.org/get-started/locally/), then install the remaining dependencies:

```bat
pip install -r inference\requirements.txt
```

PyTorch is deliberately not pinned in `inference/requirements.txt`; choosing its CUDA build is the user's responsibility. Before inference, confirm that CUDA is available:

```bat
python -c "import torch; print(torch.__version__); print('CUDA available:', torch.cuda.is_available())"
```

## Option 1: local model zip

Point the script to an nnU-Net model export already downloaded on the machine:

```bat
python inference\run_inference.py ^
  --data-dir <data_dir> ^
  --scratch-dir <scratch_dir> ^
  --model-zip <model_zip> ^
  --device auto
```

For the supplied batch and a locally downloaded model, for example:

```bat
python inference\run_inference.py ^
  --data-dir "D:\triradiatecartilage_apspine_brooks\ap_spine\batches\batch1" ^
  --scratch-dir "C:\perthesmetrics_scratch\batch1" ^
  --model-zip "C:\models\perthesmetrics_nnunet_model.zip" ^
  --device auto
```

## Option 2: download from Hugging Face

The script can download the model zip directly from [vishalgokani/perthesmetrics-nnunet](https://huggingface.co/vishalgokani/perthesmetrics-nnunet):

```bat
python inference\run_inference.py ^
  --data-dir "D:\triradiatecartilage_apspine_brooks\ap_spine\batches\batch1" ^
  --scratch-dir "C:\perthesmetrics_scratch\batch1" ^
  --model-repo vishalgokani/perthesmetrics-nnunet ^
  --device auto
```

The default remote filename is `perthesmetrics_nnunet_model.zip`. If a future model repository uses another name, add `--model-filename <filename>`.

## Outputs and options

Radiographs are converted to three-channel NIfTI only in local scratch. Predictions are converted back into eight class directories of binary BMP files under `<data-dir>/nnunet_masks` by default, using the original filenames. The output directory must not already exist, which prevents accidental replacement of earlier results. Scratch is deleted after success.

The default, `--device auto`, uses CUDA when a real CUDA allocation succeeds and otherwise falls back to CPU. Use `--device cuda` to require CUDA and fail rather than fall back, or `--device cpu` to force CPU inference. Add `--gpu 0` to select a GPU, `--output-dir <path>` to select another destination, or `--keep-scratch` to retain intermediate NIfTI files. Hugging Face authentication is only needed if the model repository is made private; in that case, run `hf auth login` first.

With CUDA selected, the script verifies a real CUDA tensor allocation and prints the GPU name before converting any images. It also launches the nnU-Net executable from the same Python environment, preventing a CPU-only nnU-Net installation elsewhere on `PATH` from being selected accidentally. Image decoding, NIfTI preprocessing, resampling, and BMP mask export still use CPU by nnU-Net design; the neural-network forward passes and sliding-window accumulation use the reported CUDA device.

## Optional figure overlays

Figure recoloring is separate from inference. Edit `OPACITY` and `COLORS` in `generate_figures.py`, or pass `--opacity`:

```bat
python inference\generate_figures.py ^
  --source-dir <data_dir> ^
  --predictions-dir <predictions_dir> ^
  --output-dir <figures_dir> ^
  --opacity 0.45
```

Run inference with `--keep-scratch` when NIfTI predictions are needed for figures. The figure command is not part of inference.
